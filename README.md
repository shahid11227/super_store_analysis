# super_store_analysis
Data analysis and visualization of a superstore dataset using Python, pandas, and matplotlib to extract business insights.
#Super Store Analysis

##  Project Description
This project performs exploratory data analysis (EDA) on a superstore dataset to understand sales, profit, and business performance across different regions, categories, and customer segments using Python.

##  Dataset
- **File name:** Sample - Superstore.csv  
- The dataset includes:
  - Order details
  - Sales and profit
  - Product categories and sub-categories
  - Regions and customer segments

##  Tools & Libraries Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

##  Analysis Performed
- Data cleaning and inspection
- Sales and profit analysis
- Category-wise and sub-category-wise performance
- Region-wise sales and profit comparison
- Visual analysis using graphs and charts

##  Key Insights
- Identified regions generating high sales but low profit
- Analyzed which product categories contribute most to profit
- Compared sales and profit trends across different segments

##  Project Structure
- `super_store_analysis.ipynb` – Main analysis notebook  
- `Sample - Superstore.csv` – Dataset used for analysis  
- `README.md` – Project documentation  

##  Objective
To gain practical experience in data analysis and visualization and extract meaningful business insights from real-world retail data.

##  Conclusion
This project demonstrates how Python-based data analysis can be used to understand business performance and support data-driven decision-making.
